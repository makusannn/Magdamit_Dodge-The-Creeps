# Dodge the Creeps! (Godot 2D Game Project)

## 📌 Project Overview
"Dodge the Creeps!" is a simple 2D game developed using the Godot Engine as part of an introductory game development activity. The objective of the game is to survive as long as possible by avoiding randomly spawning enemies ("creeps") that move toward the player.

This project demonstrates the fundamentals of 2D game development, including scene creation, player movement, enemy spawning, collision detection, scoring system, and basic game structure using Godot.

---

## 🎮 Game Objective
The player controls a character that must avoid incoming enemies for as long as possible. The game ends when the player collides with an enemy.

---

## 🧠 Learning Outcomes
Through this project, the following concepts were applied:

- Creating and organizing a 2D game project in Godot
- Player movement and input handling
- Sprite animation and character control
- Enemy spawning using randomization
- Collision detection and game over logic
- Score tracking and UI display

---

## 🛠️ Built With
- Godot Engine (2D)
- GDScript

---

## 🎮 Controls
- Arrow Keys – Move the player character
- Enter Key - Start the game
- Avoid enemies to survive as long as possible

---

## 🚀 How to Run the Project
1. Open Godot Engine
2. Import the project folder
3. Open the project
4. Press *Enter* to start the game
